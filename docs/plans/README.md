# Ambrosia Implementation Plans

This directory holds engineering implementation plans and technical specifications.

## Lifecycle
- **Active Plans (`docs/plans/`)**: Proposals and active feature/modernization plans undergoing design or implementation.
- **Completed Blueprints (`docs/plans/completed/`)**: Historical implementation blueprints for completed roadmap phases and major architectural features. These are preserved for reference and architectural context.
- **System Topic Docs (`docs/*.md`)**: The living ground-truth documentation for all current code behavior and invariants. When a plan ships, its decisions and invariants are folded directly into the relevant system topic doc.
