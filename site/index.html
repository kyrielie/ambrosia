Ambrosia

A native Calibre library reader for AO3 fanfiction

Platform:
macOS 14 or later
Built with:
Swift, AppKit, SwiftUI
Cost:
Free and open source
License:
GPL-3.0

Download Install with Homebrew

Releases are not notarized, so see first launch.

Runs on macOS 14 and later

Native Swift and AppKit/SwiftUI interface with high performance and zero web bloat.

Read-only Calibre integration

Safely reads your metadata.db without altering Calibre's database or files.

Tailored for AO3 metadata

Extracts preface metadata, fandoms, pairings, characters, and word counts into a fast local index.

Install

Homebrew

brew tap kyrielie/yggdrasil && brew install --cask ambrosia

Manual download

Get the latest build from Releases and move it to Applications.

First launch

Releases are ad-hoc signed and not notarized, so Gatekeeper blocks the first launch. Open System Settings > Privacy & Security and choose Open Anyway, or run:

xattr -dr com.apple.quarantine /Applications/Ambrosia.app

Features

Three library modes

Browse your library in full AO3 list card mode, two-pane email mode with a live reader, or the activity and reading feed.

Full-text body search

Inverted-index search across EPUB text with score ranking, token highlighting, and instant snippet navigation.

Custom EPUB reader

Read in paginated columns or continuous scrolling, with font scaling and table-of-contents navigation.

Tailored reader themes

Switch between Parchment, Sepia, Paper, Night, Slate, and Dark/Light appearance modes.

Series grouping

Automatically group multi-work series into sequence with seamless multi-chapter and multi-book navigation.

Faceted filter drawer

Filter by fandom, pairing, rating, status, language, or custom rules with real-time result counts.

Tag synonyms and expansion

Optionally seed canonical AO3 tags to enable intelligent tag autocomplete and synonym searches.

Collections and shelves

Keep track of Read Later, Liked, Skipped, and Finished fics, or create your own custom collections.

Highlights and notes

Annotate passages and export notes, saved safely in your per-library metadata database.

Reading goals and activity

Set daily or monthly reading targets, visualize reading streaks, and inspect reading milestones.

Local RSS and OPML server

Embedded local read-only feed server to publish reading lists or export metadata in OPML and CSV formats.

Keyboard shortcuts

Navigate chapters, toggle views, search, and jump to works entirely via keyboard shortcuts.
